# 08 — An image shows a skeleton while it loads

**What to build:** Between an Open Image Resource's content mounting and its picture loading, the content area shows a skeleton in the picture's place instead of an empty box, replaced by the picture on load or by the failed-image state on error. The same applies to a Reference Resource drawing an Image Resource Target and to presenting. All three draw through one component, `ResourceImage` (`packages/ui/src/ResourceImage.tsx`), mounted by `CanvasResource` for own and Reference content and by `PresentedResource` on the Stage, so it is the single change site. Today it tracks only `failed` through `onError` and has no loading state. `Skeleton` is not in `@project/ui` (it was removed with the registry `Sidebar`), and no other skeleton primitive exists there, so it is regenerated from shadcn. Starts with `$shadcn-first-ui`.

For the no-flash criterion, read the `<img>`'s `complete` (with a non-zero `naturalWidth`) on mount, so a picture the browser already has starts loaded rather than waiting for `onLoad`.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
