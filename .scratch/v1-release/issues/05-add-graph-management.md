# 05 — Add Graph management

Status: ready-for-agent
Tags: release/v1
Blocked by: none

**What to build:** Expose the existing Graph lifecycle operations through the
Sidebar and finish the selected-Edge lifecycle.

- [ ] An author can create, rename, activate, recolour and delete a Graph.
- [ ] Every Layout retains at least one Graph and gives a clear refusal when its last
      Graph would be deleted.
- [ ] Graph colour is used consistently by Edges, handles and presentation chrome.
- [ ] Edge selection exposes reconnect and delete controls after both creation and
      reconnection.
- [ ] Desktop and narrow-screen workflows have keyboard, pointer, application and
      Ladle evidence.
